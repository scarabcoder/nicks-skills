# Impeccable Companion

Use this skill when a project needs UI design critique, polishing, layout, typography, color, or frontend craft guidance alongside this architecture pack.

## Policy

- Do not vendor or copy Impeccable files into this plugin.
- Do not copy generated `.impeccable`, `.impeccable.md`, `PRODUCT.md`, `DESIGN.md`, or project-specific design artifacts from another app.
- Install or reference Impeccable separately in the target project or user environment.
- Keep this architecture pack responsible for implementation patterns and stack conventions only.

## Integration Guidance

- Use this pack for architecture, data flow, auth, permissions, database, forms, MCP, and deployment.
- Use Impeccable for visual direction, design critique, UI polish, responsive craft, accessibility audits, and frontend aesthetic improvements.
- When both apply, run architectural skills first for behavior and data contracts, then use Impeccable for interface quality.

## Boundary

This pack may say "use shadcn/Base UI, Tailwind v4, lucide, TanStack Form, accessible fields, stable component APIs." It should not prescribe brand palette, visual tone, typography personality, or product-specific design language.
